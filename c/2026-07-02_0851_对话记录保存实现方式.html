🤖 Hermes (08:52)
当前的实现是一个完整流水线，分为 5 步：

| 步骤 | 做什么 | 路径/目标 |
|------|--------|-----------|
| ① 保存 Markdown | 将对话转录为 .md 文件 | ~/hermes-conversations/conversations/YYYY-MM/YYYY-MM-DD_HHMM_标题.md |
| ② 重建站点 | 运行 build.py 生成静态 HTML | ~/hermes-conversations/site/ |
| ③ 原子提交 | 用 GitHub Git Data API（非 Contents API）一次性推所有文件 | LunaticRedMoon/hermes-log 仓库 |
| ④ 确保 Pages 模式 | 检查 build_type 为 "legacy"（非 workflow） | 跳过不必要的 Actions |
| ⑤ 触发构建 | POST /pages/builds | 最终站点 → https://lunaticredmoon.github.io/hermes-log/ |

关键设计决策：

- 原子提交而非逐个上传——避免 GitHub Pages 被多次构建触发导致冲突
- 按话题保存，不是每条消息都存。话题切换时自动保存上一话题（无需确认）
- .nojekyll 文件随提交一起推，防止 Jekyll 把中文文件名搞崩
